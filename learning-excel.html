01

Lookup functions

Find and retrieve values across tables. XLOOKUP is the modern standard; INDEX/MATCH is the universal fallback that works in every version.

Reference data — product prices

Sheet1 — product prices
ABCD
5ProductCategoryPriceStock
6LaptopElectronics99912
7DeskFurniture21030
8BlenderKitchen658
9NotebookOffice4.5240
10MonitorElectronics28017

XLOOKUP — the modern lookup

Looks in any direction, returns errors gracefully, no column-counting. =XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])

What it doesFormulaResult
Price of 'Blender'=XLOOKUP("Blender",A6:A10,C6:C10)65
Price, safe if missing=XLOOKUP("Router",A6:A10,C6:C10,"Not found")Not found
Category of 'Monitor'=XLOOKUP("Monitor",A6:A10,B6:B10)Electronics
Return whole row (spills)=XLOOKUP("Desk",A6:A10,B6:D10)Furniture, 210, 30

INDEX + MATCH — works everywhere

INDEX(return_range, MATCH(lookup_value, lookup_range, 0)) — MATCH finds the position, INDEX returns the value there.

What it doesFormulaResult
Price of 'Laptop'=INDEX(C6:C10,MATCH("Laptop",A6:A10,0))999
Stock of 'Notebook'=INDEX(D6:D10,MATCH("Notebook",A6:A10,0))240
Two-way (Desk / Price)=INDEX(A6:D10,MATCH("Desk",A6:A10,0),MATCH("Price",A5:D5,0))210
★Your turn: price of 'Monitor' with XLOOKUP, and stock of 'Desk' with INDEX/MATCH.

=XLOOKUP("Monitor",A6:A10,C6:C10) → 280

=INDEX(D6:D10,MATCH("Desk",A6:A10,0)) → 30

⚠ Common mistakes
  • VLOOKUP defaults to approximate match — always add FALSE (or 0) as the last argument for exact match.
  • VLOOKUP only looks rightward from its key column. XLOOKUP and INDEX/MATCH look any direction.
  • MATCH needs a 0 as its third argument for exact match; omit it and unsorted data returns wrong results.
  • Text vs number mismatch (lookup value text, table numbers) fails silently — check with ISNUMBER.

Logic & conditional aggregation

IF / IFS for decisions · SUMIFS, COUNTIFS, AVERAGEIFS for criteria-based totals · SUMPRODUCT for weighted math.

Live examples

What it doesFormulaResult
Grade Alice's sales (IFS)=IFS(C6>=50000,"A",C6>=40000,"B",TRUE,"C")B
Total sales, North=SUMIFS(C6:C10,B6:B10,"North")93000
Count reps over target=COUNTIFS(C6:C10,">=45000")2
Avg sales in South=AVERAGEIFS(C6:C10,B6:B10,"South")42500
Weighted total=SUMPRODUCT(C6:C10,D6:D10)/SUM(D6:D10)42073.17
★Your turn: total sales for North, and count of reps with sales ≥ 40000.

=SUMIFS(C6:C10,B6:B10,"North") → 93000

=COUNTIFS(C6:C10,">=40000") → 3

⚠ Common mistakes
  • SUMIFS puts the sum range first; SUMIF puts it last. Mixing them up is the #1 error.
  • Criteria with operators must be quoted: ">=45000". Combine with a cell via ">="&B1.
  • Every criteria range in SUMIFS/COUNTIFS must be the same size, or you get a VALUE error.
  • IFS has no built-in else — add TRUE as the final condition or you'll get an N/A error.

Clean, split and join text · calculate durations and working days · reshape strings into data.

Sheet1 — employees

Live examples

Dates are just numbers — subtract them, or use DATEDIF / NETWORKDAYS. Newer TEXTBEFORE/TEXTSPLIT make delimited data easy.

What it doesFormulaResult
First name (before space)=LEFT(A6,FIND(" ",A6)-1)Alice
Last name (after space)=MID(A6,FIND(" ",A6)+1,50)Wong
Username (before @)=TEXTBEFORE(B6,"@")alice.wong
Join name + email=TEXTJOIN(" | ",TRUE,A6,B6)Alice Wong | alice…
Years of service=DATEDIF(C6,TODAY(),"Y")5
Working days since hire=NETWORKDAYS(C6,TODAY())~1410
Month-end of hire date=EOMONTH(C6,0)2021-03-31
★Your turn: username from Ben's email, and years of service for Carla.

=TEXTBEFORE(B7,"@") → ben.carter

=DATEDIF(C8,TODAY(),"Y") → 4 (as of build date)

⚠ Common mistakes
  • Dates that won't do math are probably text — left-aligned by default. Fix with DATEVALUE or Text-to-Columns.
  • FIND is case-sensitive; SEARCH is not. Pick deliberately.
  • DATEDIF is quirky — the "MD" unit can give wrong results; prefer "Y", "M", or "D".
  • TEXTBEFORE / TEXTSPLIT are 365-only. On older Excel use LEFT/MID with FIND.

Dynamic arrays

One formula, many results that "spill". FILTER · SORT · UNIQUE · SEQUENCE · the spill operator (#). Excel 365 / 2021.

Sample data

Sheet1 — sales by rep
ABC
5RepRegionSales
6AliceNorth42000
7BenSouth38000
8CarlaNorth51000
9DiegoWest29000
10EllaSouth47000
11FrankNorth33000

Live examples (results spill downward)

A dynamic array returns many values from one cell — they spill into the cells below or right. Reference a spill range with its top cell + # (e.g. E6#).

What it doesFormulaSpills to
Unique regions=UNIQUE(B6:B11)North, South, West
Reps in North only=FILTER(A6:A11,B6:B11="North")Alice, Carla, Frank
Sales sorted high→low=SORT(C6:C11,1,-1)51000, 47000, …
Numbers 1..5=SEQUENCE(5)1, 2, 3, 4, 5
Top 3 sales=TAKE(SORT(C6:C11,1,-1),3)51000, 47000, 42000
★Your turn: list reps in South, and a unique list of regions.

=FILTER(A6:A11,B6:B11="South") → Ben, Ella

=UNIQUE(B6:B11) → North, South, West

⚠ Common mistakes
  • A SPILL error means something blocks the spill range — clear the cells below/right.
  • Reference a whole spilled range with the # operator (E6#); don't hard-code the size.
  • These are Excel 365 / 2021 only. Older versions return a NAME error.
  • Don't wrap a dynamic array inside a Table — Tables don't allow spilling. Use a normal range.
05

LAMBDA & LET

Build your own reusable functions. LET names intermediate steps; LAMBDA turns a formula into a callable function; MAP/REDUCE/BYROW iterate.

LET — readable formulas

LET(name1,value1, name2,value2, …, calculation) — define variables once, reuse them, make formulas readable and faster.

What it doesFormulaResult
10% off + 8% tax=LET(p,100, disc,p*0.9, disc*1.08)97.2
Circle area (r=5)=LET(r,5, PI()*r^2)78.54

LAMBDA — custom functions

LAMBDA(param1,param2, calculation) defines a function. Name it in Name Manager (Formulas ▸ Name Manager) to reuse it everywhere.

Named functionDefinitionCall it like
ToFahrenheit=LAMBDA(c, c*9/5+32)=ToFahrenheit(100) → 212
Commission=LAMBDA(sales,rate, sales*rate)=Commission(50000,0.05) → 2500
FullName=LAMBDA(first,last, first&" "&last)=FullName("Ada","Lovelace")

MAP / BYROW / REDUCE — iterate a LAMBDA

What it doesFormula
Add 10% to each of 1..5=MAP(SEQUENCE(5),LAMBDA(x,x*1.1))
Sum via REDUCE=REDUCE(0,SEQUENCE(5),LAMBDA(acc,x,acc+x))
Row totals (BYROW)=BYROW(A1:C3,LAMBDA(r,SUM(r)))
Practice

In Name Manager, create Discount = LAMBDA(price,pct, price*(1-pct)), then call =Discount(200,0.15). You should get 170.

⚠ Common mistakes
  • A LAMBDA must be saved in Name Manager before you can call it by name across the sheet.
  • In LET, define a name before you use it — order matters, left to right.
  • The final argument of LET is the calculation (no name) — forgetting it is common.
  • LAMBDA/LET are 365 / 2021 only. Keep names short or the formula gets hard to debug.
06

Power Query

Import data from anywhere, clean it with recorded steps, and refresh with one click. A desktop guide — follow it in Excel using the Practice Dataset.

The idea

Power Query records every cleaning step as a repeatable script (the "Applied Steps"). When source data changes, hit Refresh and all steps re-run — no manual re-cleaning, ever. It lives at Data ▸ Get & Transform Data.

Getting started

  1. Load the table Click any cell in the 'Sales' table ▸ Data ▸ From Table/Range. The Power Query Editor opens.
  2. Applied Steps Every action appears on the right. Click a step to see the table at that point; delete a step with ✕ to undo it.
  3. Set data types Select a column ▸ set type via the ABC/123 icon. Correct types prevent downstream errors.

Core transformations

  • Remove / keep columns — right-click a header ▸ Remove, or select the keepers ▸ Remove Other Columns.
  • Filter rows — the column ▼ dropdown, or Number/Text/Date Filters.
  • Split column — Home ▸ Split Column ▸ By Delimiter. Turns 'Smith, John' into two columns.
  • Custom column — Add Column ▸ Custom Column, e.g. = [Qty] * [UnitPrice].
  • Group By — Home ▸ Group By: group by Region, aggregate Sum of Revenue. Like a PivotTable but as a step.
  • Unpivot — select value-in-header columns (Jan, Feb, Mar) ▸ right-click ▸ Unpivot. Wide becomes tidy long data.

Combining queries

  • Merge (like VLOOKUP/JOIN) — Home ▸ Merge Queries. Pick a key column in each and a join kind.
  • Append (stack tables) — Home ▸ Append Queries. Stacks rows of same-column tables, e.g. 12 monthly files.
  • Combine a folder — Data ▸ Get Data ▸ From File ▸ From Folder. Add a file → Refresh → included automatically.
Practice

Load 'Sales' → filter Revenue > 1000 → Group By Region with Sum of Revenue → Close & Load to a new sheet. Change a source value and Refresh to watch it update.

07

Power Pivot & DAX

Handle millions of rows across related tables and write DAX measures. The engine behind serious Excel analytics.

Concepts

  • Data Model — an in-memory database inside your workbook. Tables can be related, so no giant flat sheet or endless VLOOKUPs.
  • Star schema — one central 'fact' table linked to 'dimension' tables (Calendar, Products, Regions). Keeps models fast and clean.
  • Enable it — File ▸ Options ▸ Add-ins ▸ COM Add-ins ▸ tick 'Microsoft Power Pivot for Excel'.

Building the model

  1. Add tables Load to the model via Power Query (Close & Load To ▸ Add to Data Model) or Power Pivot ▸ Add to Data Model.
  2. Create relationships Power Pivot ▸ Manage ▸ Diagram View. Drag a key field to the matching key in another table. One-to-many is typical.
  3. A Calendar table Add a dedicated date table and mark it (Design ▸ Mark as Date Table). Required for time-intelligence DAX.

DAX measures

Measures calculate at the moment of use, respecting whatever filters the PivotTable applies.

-- core measures
Total Revenue := SUMX(Sales, Sales[Qty] * Sales[UnitPrice])
Total Qty     := SUM(Sales[Qty])
Avg Order     := DIVIDE([Total Revenue], DISTINCTCOUNT(Sales[OrderID]))

-- time intelligence (needs a marked Calendar table)
Revenue YTD   := TOTALYTD([Total Revenue], Calendar[Date])
Revenue LY    := CALCULATE([Total Revenue], SAMEPERIODLASTYEAR(Calendar[Date]))
YoY %         := DIVIDE([Total Revenue]-[Revenue LY], [Revenue LY])
Key functions
  • CALCULATE — the most important DAX function; changes the filter context of a calculation.
  • SUMX / AVERAGEX — iterators: evaluate an expression row-by-row, then aggregate.
  • DIVIDE — safe division; returns blank instead of a divide-by-zero error.
  • RELATED — pull a column from a related table, like a lookup across the relationship.
Practice

Add 'Sales' to the Data Model, create the Total Revenue measure, build a PivotTable of Revenue by Region and Category, then add a YoY % measure using a Calendar table.

08

PivotTables

Summarize thousands of rows in seconds by dragging fields. The fastest way to explore data.

Basics

  • Create one — click inside the 'Sales' table ▸ Insert ▸ PivotTable ▸ New Worksheet.
  • The four areas — Rows (categories down the side), Columns (across the top), Values (the numbers), Filters (page-level).
  • Change the math — click a Values field ▸ Value Field Settings ▸ Sum, Count, Average, Max.
  • Show values as — Value Field Settings ▸ Show Values As ▸ % of Grand Total, % of Column, Running Total, Rank.

Organizing

  • Group dates — right-click a date in Rows ▸ Group ▸ Months/Quarters/Years.
  • Group numbers — right-click a number field ▸ Group ▸ set bin size (e.g. Revenue into 0–500, 500–1000…).
  • Sort & Top N — Row Labels ▼ ▸ Value Filters ▸ Top 10.
  • Layout — Design ▸ Report Layout ▸ Tabular Form for a clean database-style look.

Interactivity

  • Slicers — PivotTable Analyze ▸ Insert Slicer. Connect one to several pivots via Report Connections.
  • Timeline — Insert Timeline for a date slider.
  • Calculated Field — Fields, Items & Sets ▸ Calculated Field, e.g. Margin = Revenue*0.3.
  • GETPIVOTDATA — clicking a pivot cell in a formula writes this to pull that exact value reliably.
Practice

Build Revenue by Region (Rows) × Category (Columns); add a Region slicer; group Date by Quarter; show Revenue as % of Grand Total.

09

Validation & formatting

Control what can be entered, build dropdowns, and let cells format themselves based on their values.

Data validation

  • Simple dropdown — Data ▸ Data Validation ▸ Allow: List ▸ Source: comma-separated items or a range.
  • Numeric limit — Allow: Whole number ▸ between ▸ set min/max. Add an Error Alert to reject bad entries.
  • Dependent dropdown — name each sub-list (Formulas ▸ Create from Selection). Second cell's List source: =INDIRECT(A2).

Conditional formatting

Home ▸ Conditional Formatting restyles cells by value: highlight rules, data bars, colour scales, icon sets, or a formula rule for whole-row highlighting.

Practice

Select a Sales column ▸ Conditional Formatting ▸ Data Bars. Then add a Highlight Cells rule for values greater than 45000.

⚠ Common mistakes
  • Data Validation only blocks typed entries — pasting over a cell can bypass it.
  • Dependent dropdowns via INDIRECT need list names exactly matching the first dropdown's values (no spaces).
  • Conditional-formatting formula rules must start with = and use the active cell's reference.
  • Too many rules on huge ranges slow the file down — keep them targeted.
10

VBA & macros

Automate repetitive work. Record a macro, read the code, then write your own with variables, loops and logic.

When to use it

Reach for VBA when a job repeats, has many manual steps, needs a custom message box or button, or goes beyond formulas/Power Query. Rule of thumb: formulas for live calculations, Power Query for repeatable import/clean, VBA for full automation. Use the lightest tool that does the job.

Setup

  • Show the Developer tab — File ▸ Options ▸ Customize Ribbon ▸ tick 'Developer'.
  • Open the editor — Alt+F11. Insert ▸ Module creates a blank code sheet.
  • Save as .xlsm — macros can't live in a normal .xlsx or they're stripped on close.

Record first, learn from it

Developer ▸ Record Macro ▸ do your steps ▸ Stop. Excel writes the VBA for you. Then Alt+F11 to read it. Recorded code is verbose (lots of .Select); clean it up by acting on ranges directly.

Anatomy of a macro

Option Explicit   ' forces variable declaration, catches typos

Sub Totals()
    Dim lastRow As Long, i As Long
    Dim total As Double
    lastRow = Cells(Rows.Count, "I").End(xlUp).Row
    For i = 5 To lastRow
        total = total + Cells(i, "I").Value
    Next i
    MsgBox "Total revenue: " & Format(total, "$#,##0")
End Sub

Core building blocks

' IF / conditionals
If Cells(i, "I").Value > 1000 Then
    Cells(i, "J").Value = "High"
ElseIf Cells(i, "I").Value > 500 Then
    Cells(i, "J").Value = "Mid"
Else
    Cells(i, "J").Value = "Low"
End If

' loop every sheet
Dim ws As Worksheet
For Each ws In ThisWorkbook.Worksheets
    ws.Range("A1").Font.Bold = True
Next ws

' With block — cleaner and faster
With Range("A4:I4")
    .Font.Bold = True
    .Interior.Color = RGB(33, 42, 59)
    .Font.Color = vbWhite
End With
Good habits
  • Avoid .Select — Range("B2").Value = 5 beats selecting then acting on Selection.
  • Speed up big loops — set Application.ScreenUpdating = False and Calculation = xlManual at the start; restore at the end.
  • Handle errors — On Error GoTo Handler so a macro fails gracefully.
  • Security — macros are powerful; keep .xlsm files from unknown sources closed.
★Exercise: loop down column I and, in column J, write 'High' where Revenue > 1000 else 'Low'.
Sub TagRevenue()
    Dim lastRow As Long, i As Long
    lastRow = Cells(Rows.Count, "I").End(xlUp).Row
    For i = 5 To lastRow
        If Cells(i, "I").Value > 1000 Then
            Cells(i, "J").Value = "High"
        Else
            Cells(i, "J").Value = "Low"
        End If
    Next i
End Sub
